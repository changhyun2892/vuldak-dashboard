# 불닭·삼양식품 대시보드 자료조사 전달본 v2

분석기간 2023~2025년 / 비교기준 2022년 / 조사일 2026-10-27

기존 전달본에서 후속 확장으로 미뤘던 분기 실적, 과거 가동률, 2022 기준잔액, 해외법인 과거 실적, 브랜드 매출 보도, 가격 표본, 출시·유통 연표를 추가했다. 이 폴더는 대시보드 구현에 쓰는 자료·기획 패키지다. 실행 가능한 웹사이트 코드는 포함하지 않는다.

## 읽는 순서

1. 03_추가조사_결과와_잔여한계.md: 보완 결과와 남은 검증 한계.
2. 01_대시보드_기획과_구현안내.md: 화면·기능·계산식.
3. 02_경영해석과_출처.md: 교수님께 설명할 경영 관찰.
4. data/: 구현용 CSV. sources/: 사용자 원본. 검증결과.json: 데이터 무결성 점검 결과.

## 자료 사용 기준

공시 실적, 언론보도, 계산값, 원인 가설을 구분한다. 회사 연결 이익을 불닭 이익으로 바꾸지 않는다. 공개되지 않은 수치를 만드는 것은 자료조사 완성이 아니다. 해당 항목도 지우지 않고 연구 한계와 근거를 남겼다.

## 구현과 발표

교수님께 발표하려면 대시보드를 로컬에서 실행해 시연해도 된다. 연구소 홈페이지 연결이나 공개 배포는 발표의 필수 조건이 아니다. 접속 가능한 공유 링크가 필요할 때 별도로 배포하면 된다.

동료에게 이 폴더 전체를 전달하고 01 문서 마지막의 시작 지시문을 Claude Code에 입력한다. 2022 값은 비교 계산용이며 화면의 기본 분석 연도는 2023~2025를 유지한다.
