# 불닭의 글로벌 성장과 삼양식품의 경영성과

추가조사 반영 전달본 v2 · 분석기간 2023~2025년 · 정리일 2026-10-27

## 1. 목적과 자료 범위

이 대시보드는 불닭을 중심으로 해외 판매가 확대되는 과정에서 삼양식품의 매출·이익·생산·현금이 어떻게 변했는지 설명한다. 대상 사용자는 경영학 수업 교수와 학생이다. 투자 추천이나 실시간 시장 분석 도구가 아니다.

재무 수치는 제공된 2026.03.18 사업보고서 원본의 연결재무제표를 기준으로 추출했다. 최신 정정공시 반영본이라는 의미는 아니다. 보고서 페이지는 하단에 인쇄된 Page 번호다. 2023·2024·2025년은 제63·64·65기와 대응한다.

회사 전체, 면스낵, 소스조미소재, 해외법인, 불닭 브랜드 범위를 반드시 구분한다. 불닭 브랜드 연간 매출은 별도 보도값 CSV에 수록했다. 브랜드 영업이익은 공개 자료에서 확인되지 않았다. 회사 실적을 불닭 실적으로 바꾸어 쓰지 않는다.

## 3. 구현할 기능

1. 카드에 값·단위·범위·전년 증감 표시. 비율 변화는 %p, 금액 성장률은 % 사용.
2. 마우스 또는 터치로 원자료 수치와 출처를 확인한다.
3. 출처 버튼에 문서명·인쇄 페이지·원문 파일 링크·계산식을 표시한다.
4. 해외법인 2023~2025 매출은 foreign_entities.csv의 원화 환산 종속기업 요약재무정보를 사용한다. 현지통화 설명용 파일과 연결하지 않는다. 2023 유럽법인은 설립 전으로 표시한다.
5. 2022 기준자료를 보완했으므로 2023 성장률·회전율도 표시한다. 2023~2024 공장 가동률도 제공한다. 실제 결측·설립 전 항목만 0 대신 해당 사유를 표시한다.
6. 파일을 앱 내부 정적 데이터로 읽는다. 초기 버전에는 로그인·서버·실시간 AI 호출이 필요하지 않다. 배포 방식은 구현 담당자가 선택한다.
7. 해설은 사전 검증된 문구로 제공한다. AI가 즉석에서 사건 원인을 생성하지 않는다.

## 5. 계산식

- 영업이익률 = 영업이익/매출액×100.
- 매출원가율 = 매출원가/매출액×100; 판관비율 = 판매비와관리비/매출액×100.
- 성장률 = (당기/전기−1)×100; 전기 미확보 또는 0이면 계산하지 않는다.
- 면스낵 수출 비중 = 면스낵 수출/(면스낵 수출+내수)×100. 회사 전체 해외 매출 비중과 다르다.
- 유형자산 취득 후 현금 차액 = 영업활동현금흐름−유형자산 취득 현금지출. 무형자산 등은 미포함이므로 ‘총 잉여현금흐름’으로 표기하지 않는다.
- 부채비율 = 부채총계/자본총계×100; 유동비율 = 유동자산/유동부채×100.
- 재고회전율 = 매출원가/기초·기말 평균 재고자산.
- 매출채권회전율 = 매출액/기초·기말 평균 매출채권. 외상매출액 대신 전체 매출액을 사용한다.
- 사업별 성장 기여액 = 당기 사업 매출−전기 사업 매출. 면스낵·소스 외 항목은 ‘나머지 매출·조정’으로 묶어 연결매출 증가액과 차이를 맞춘다. 이는 원문 단일 사업부가 아니다. 사업 표는 백만원 단위라 반올림 차이를 허용한다.

## 6. 오해 방지 규칙

생산능력·생산실적은 각 기간 기준가격을 적용한 금액이다. 봉지 수로 바꾸지 않는다. 시간 기준 공시 가동률을 생산금액/능력금액으로 다시 계산하지 않는다. 2025 하반기 밀양2공장 가동, 밀양 면류 생산금액 산정과 공장 가동가능시간 기준 변경을 표시한다. 금액 기준 생산능력 증가를 물량 증가율로 단정하지 않는다.

해외법인 매출은 연결 내부거래 제거 전 성격이 포함될 수 있으므로 연결 매출에 더하지 않는다. 기본 법인 비교표는 천원 단위로 통일되어 있다. 현지통화 보조 파일은 통화별 카드로만 표시한다. 법인 매출을 해당 국가 최종소비자 매출로 단정하지 않는다.

검색 자료는 Google의 buldak와 네이버의 불닭볶음면·까르보불닭이라는 다른 검색어·플랫폼 조건이다. 네이버 ‘불닭’은 그룹명이다. 세 추이의 지수 수준은 직접 비교하지 않는다. 전 세계에는 미국이 포함되어 있어 서로 독립된 표본이 아니다. 국가별 점수는 검색 건수나 판매량 순위가 아니다. Worldwide 원본의 2022-12 행은 정리본에서 제외했다. 날짜 표기/내보내기 경계 이상 가능성은 원본을 보존하고 추후 필요 시 재다운로드로 확인한다. 파일명의 20261027은 내보내기 시각이며 분석 종료일로 사용하지 않는다.

관련 검색어의 increase percent 비교 기준은 원본만으로 확인되지 않으므로 증가율을 주 KPI로 사용하지 않는다. Breakout은 원문 표기를 유지하고 정해진 증가율로 치환하지 않는다. 리콜·암 관련 검색은 소비자의 질문이며 사실 확인 자료가 아니다.

## 7. 구현 완료 확인

- 2025 매출 약 23,517.9억원, 영업이익 약 5,241.9억원, 이익률 22.3%, 면스낵 수출 비중 84.6%.
- 매출−매출원가−판관비=영업이익을 3개년 모두 확인한다.
- 2025 영업현금흐름 약 3,092.9억원, 유형자산 취득 지출 약 4,489.9억원.
- 검색은 각 지역 36개 월, 국내 최고점 2025-02, 전 세계·미국 최고점 2025-08.
- 결측값은 0으로 그래프에 그리지 않는다. 공장 합계와 개별 공장을 동시에 더하지 않는다.
- 2023년 선택, 2024년 선택, 2025년 선택과 모바일 폭에서 카드·출처·결측 안내를 확인한다.
- 외부 사건의 날짜 정밀도와 출처를 유지한다. 2025 연표에 2026 누적 판매 기록을 넣지 않는다.

## 8. 추가조사 반영 화면

- 실적 영역: 연간/분기 전환을 추가한다. 분기는 2023-Q1~2025-Q4이며 누적과 혼용하지 않는다. 분기 매출·영업이익·이익률을 표시한다.
- 브랜드 영역: 3개년 매출 보도값은 ‘언론보도 기준·근사값’ 배지를 붙인다. 브랜드 영업이익은 표시하지 않는다.
- 생산 영역: 2023~2025 시간 가동률을 비교하되 2025 산정 변경을 명시한다.
- 해외법인 영역: 같은 원화 환산 기준으로 연도별 비교하고 현지통화 설명은 별도 툴팁에 둔다.
- 시장 참고 탭: 가격은 2026 조회 표본이므로 연도 선택과 분리한다. 2023~2025 가격으로 소급하지 않는다.
- 검색 영역: 최고점과 관련 보도를 나란히 제시하되 인과관계 미확인을 명시한다. 상세 문구는 03 문서를 사용한다.
- 조사 현황 탭: research_status.csv의 모든 항목을 보여 주고 확인된 결과와 한계를 함께 공개한다.
