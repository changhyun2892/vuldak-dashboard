# 불닭 경영대시보드 수정 전달본

작성·확인: 2026-11-03, 재검증 및 수정. 기존 2023~2025 분석자료와 교수 피드백을 바탕으로 자료를 보완한 전달본이다. 2022년은 성장률·회전율 비교용이다. 이 자료는 기존 대시보드 수정용이며 실행 코드는 없다. 주가 연동은 제외한다.

## 읽는 순서
1. `01_수정_구현지침.md`: 기존 화면에 반영할 작업과 우선순위.
2. `02_검증결과와_한계.md`: 대조 범위, 발견한 문제, 미확인 항목.
3. `data/`: 화면 연결용 CSV와 `audit_ledger.csv`, `audit_source_links.csv`, `source_registry.csv`.
4. `sources/`: 기존 원자료와 공시에서 추출한 표의 행. `reference/`의 과거 지침은 참고만 하며 이 문서가 우선한다.

## 주의
`data/financials.csv`, `quarterly_financials.csv`, `calculated_metrics.csv`는 기업 구분 열이 추가된 새 버전이다. 기존 파일과 행 구조가 달라 기존 코드를 확인한 뒤 연결한다. 신규 기업 선택 시 해당 기업의 데이터만 표시한다. 별도 확인이 필요한 항목은 02 문서를 따르며 이전 `research_status.csv`는 이전 조사 시점의 참고 기록이다.

기업 연결재무 수치와 브랜드 수치를 분리한다. 판매경로 분모·기간과 공급처-공장 간 거래량이 확인되지 않은 부분은 추정하지 않는다. DART 키는 포함하지 않았다. 최종 대시보드 표시값과 실제 API 연결·최신 정정공시 전체 이력은 확인하지 않았다.

## 추가 보완자료
농심 사업지역별 외부고객 수익과 2022~2024년 재무 비교열 대조 기록을 추가했다. 기준·제약은 02 문서의 추가 보완 항목을 먼저 확인한다.
