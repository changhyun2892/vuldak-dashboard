# 누나에게 전달할 수정 지침

기존 대시보드를 유지하면서 아래 순서로 적용한다. 실제 기존 소스는 확인하지 못했으므로 변수명·구조는 담당자가 확인한다.

## 1. 데이터 신뢰도
- `data/audit_ledger.csv`를 검증 상세에 연결하고 대상 행·값·원문 위치·대조 방법·상태를 보여준다. `audit_id` 또는 `audit_ids`로 원자료와 연결한다. `audit_source_links.csv`에서 audit_id에 연결된 출처 ID를 각각 조회하고 `source_registry.csv`의 URL·원본 파일을 연다. 한 감사 항목에 출처가 여럿이면 모두 보여 준다.
- 기존과 신규 추출은 구분한다. 농심 신규 수치는 공시 원문 행에서 추출한 값이며, 독립적인 제3자 검증이나 최신 정정 확인이 아니다. 대조되지 않은 지표에는 완료 표시를 붙이지 않는다.

## 2. 기업 전환과 비교
- 재무·분기는 `company_id` SY=삼양식품, NS=농심. 연간 `financials.csv`의 고유키는 (company_id, year, metric), 분기는 (company_id, year, quarter). 원 단위 값을 억원으로 표시할 때 1억원으로 나눈다.
- 연결 기준 매출·영업이익·영업이익률·원가율·부채비율·유동비율과 영업현금 흐름을 비교한다. `calculated_metrics.csv`의 비율은 0~100. 비교 시 회사 사업 구성과 회계 분류 차이를 명시한다.
- 농심 사업별 값은 `nongshim_segments.csv`: 제품·상품 등 통합, 매출에누리 별도. 삼양 면스낵과 동일 범위가 아니므로 수출비중·브랜드·제품별 순위를 강제로 비교하지 않는다. 농심의 사업지역별 외부고객 수익은 `nongshim_region_revenue.csv`에 별도 제공한다. 삼양 해외법인의 내부거래 제거 전 매출과 직접 비교하지 않는다. 농심 검색·브랜드·개별 해외법인 등의 데이터는 제공되지 않은 항목을 '자료 없음'으로 표시한다.
- 농심 가동률은 `nongshim_utilization.csv`, 삼양은 `production.csv`. 공장과 제품유형 집계가 달라 직접 순위화하지 않는다. 농심 2024 상해농심은 원문 내부 불일치가 있어 비교·판정에서 제외하고 확인 필요 배지 표시.

## 3. 공급사슬
- `raw_material_prices.csv`의 6개 재료×3년 원/kg 가격, `suppliers.csv`의 주요 매입처, `production.csv`의 공장/품목, `sales_channels.csv`의 사업별 경로를 클릭 가능한 단계형 카드로 표시한다.
- 원문은 개별 공급처→개별 공장 물량, 공장→특정 고객의 물량을 확인해 주지 않는다. 해당 연결은 미확인으로 표시하고 화살표 굵기를 수량이나 매출액으로 나타내지 않는다. 가격은 단가이지 물량이 아니다.
- 판매경로 비중은 2025 사업보고서 표에 실렸으나 표 자체에 기준연도·분모의 세부 정의가 명확하지 않다. 서로 다른 사업군의 비중을 합산하거나 회사 전체 매출로 환산하지 않는다. 소스·조미소재는 표의 병합된 그룹으로 유지한다.
- 해외법인 매출은 `foreign_entities.csv`의 연결 제거 전 요약재무정보이며 회사 연결매출에 더하거나 그 국가의 소비자 매출로 바꾸지 않는다.

## 4. 사용자 관점과 질의
성장 지속성, 이익의 질, 현금·재무 안정성, 해외·환율 위험, 생산 여력의 다섯 관점에 '관찰값 / 확인할 질문 / 한계'를 표시한다. 근거 없이 우수·위험 등급이나 임계치를 확정하지 않는다. 예: 매출 성장률과 영업이익률을 함께 비교, 영업현금흐름과 유형자산 취득 지출 차액 확인, 공시 가동률의 산정기준 변경 확인.

현재 내부 데이터 질의 기능을 강화한다. 예시 질문: '2025년 두 회사 영업이익률은?', '2024년 대비 삼양 2025 매출 증가율은?', '2025 밀양 면류 가동률은?' 계산 시 사용 행·산식·단위·기간·출처를 표시한다. 데이터에 없는 질문은 미확인으로 답하고 검색지수의 인과관계를 단정하지 않는다. 자유형 AI 답변을 새로 연동했거나 검증했다고 가정하지 않는다.

## 5. DART (후속)
인증키는 이미 발급됐지만 이 전달본에서 실제 접속은 시험하지 않았다. 서버 환경변수에 저장하고 브라우저 코드·CSV·저장소에 넣지 않는다. 수동 조회와 정기 조회/검토 대기는 별개다. 자동 반영 전 원문·단위·연결/별도·누적/단일분기·정정 여부를 사람이 확인한다. 공식 개발가이드: https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020

## 완료 확인
2025 삼양 매출 약 23,517.9억원, 영업이익 약 5,241.9억원; 농심 매출 약 35,143.2억원, 영업이익 약 1,839.3억원. 두 회사 각 12분기의 연간 합과 계정 산식을 확인한다. 기업·연도·분기 변경, 미확인 값, 출처 버튼과 모바일 화면을 실제 사이트에서 별도로 검사한다.
